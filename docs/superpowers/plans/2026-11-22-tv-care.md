# TV Care Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a safe, guarded "Care" toolkit to TVunboxed for app/storage audit, user-file cleanup with backup, APK sideloading through the TV's own installer, a web UI tab, and a CLI.

**Architecture:** A new stdlib-only `tvunboxed/tvcare.py` owns all scope validation and business logic. The HTTP server gains thin `/api/care/*` endpoints that delegate to it. The web UI gains a Care tab. A CLI dispatch in `__main__.py` reuses the same module. All destructive operations require an exact SHA256-derived token emitted by the audit report and a full WebDAV backup before each delete.

**Tech Stack:** Python 3.9+, standard library only, existing `tvunboxed.tvdav.WebDavClient`, `tvunboxed.tvapps.fetch_app_list`, `tvunboxed.share.open_file_message`, vanilla HTML/CSS/JS.

## Global Constraints

- No writes outside `/sdcard/`. Never touch `/system`, `/data`, `/adb_keys`, boot/recovery, or any auth path.
- No ADB authorization bypass, root exploit, key injection, firmware flashing, or system-package removal.
- No new third-party dependencies.
- All destructive actions require the exact confirmation token from `make_confirm_token(sorted(paths))`.
- Every deleted file is first downloaded to a local backup directory.
- Port 8000 must remain LAN-only; never port-forward.
- No commit unless the user explicitly asks.
